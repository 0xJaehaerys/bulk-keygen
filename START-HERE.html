Start BULK Keygen locally

No folder commands. You can open Terminal anywhere.

First, extract the entire ZIP. Keep START.mjs, scripts and dist together. If needed, install Node.js 24 or later from its official website.

1. Open a terminal

macOS: press ⌘ Space, type Terminal, press Return.

Windows: open Windows Terminal with a PowerShell or Command Prompt tab. Use a normal window, not Administrator or WSL.

Linux: open your usual terminal.

2. Type, drag, press Enter

  1. Type node followed by one space. Do not press Enter yet.
  2. Drag the START.mjs file from this extracted folder into the terminal input area. This inserts its full path. Drag the file, not the folder, and keep it with the other app files.
  3. Press Enter. The app finds its files itself.

If dragging does not work on Windows: Shift-right-click START.mjs → Copy as path, then paste after node . Keep the quotes around the path.

Alternative on Windows

Open this folder in File Explorer. Type cmd in its address bar, press Enter, then run node START.mjs.

3. Open the printed address

Open the exact http://127.0.0.1:PORT address printed in the terminal in the desktop browser with Backpack installed.

Keep the terminal open while using the app. Press Ctrl+C when finished. To start again, repeat step 2.

Backpack is recommended for subaccounts. Phantom supports main-account agent keys only in this tool; those also cover all subaccounts.

Troubleshooting & safety

Node not found: install Node.js, then reopen Terminal. File not found: extract the whole ZIP and drag START.mjs again. Ports busy: add a space and 3030 after the file path before pressing Enter.

This is a setup guide, not the wallet app. This HTML file runs no scripts. The wallet app opens only at the printed local address.

No npm install, administrator terminal, automatic updates or security-setting changes are needed. Keep Gatekeeper, SmartScreen and wallet checks enabled. This is not a signed/notarized native app.

Never share private keys, backups, passwords or signed requests with an AI agent. AGENT-SETUP.txt contains public setup instructions you can share instead. README-LOCAL.md has the full guide.

A local copy reduces reliance on future website changes. You still need to trust the downloaded app, extensions and computer. Account lookup and registration need internet access to BULK. This tool is not independently audited; no zero-risk guarantee is made.
